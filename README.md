# Портфолио технического писателя

В портфолио собраны кейсы и самостоятельные учебно-практические
документы. Материалы показывают работу с информационной архитектурой,
процессами документации и техническими инструкциями.

## Проекты

### [1. Корпоративная база знаний](01-corporate-knowledge-base/README.md)

Коммерческий кейс о создании и развитии базы знаний: информационная
архитектура, модель доступа и жизненный цикл документации.

### [2. Диагностика проблем с сетевым подключением](02-network-troubleshooting-guide/README.md)

Учебно-практическое руководство для первой линии поддержки и
пользователей. Помогает последовательно локализовать проблему: от
подключения устройства до DNS и конкретного приложения.

## Навыки

- структурирование сложной информации;
- подготовка инструкций и troubleshooting-документации;
- Markdown и Mermaid;
- работа с технической терминологией;
- редактура и проверка понятности документа;
- базовое понимание сетевого взаимодействия, DNS и клиентских приложений.
